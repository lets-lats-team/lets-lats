## clause_no 규칙 (정답 입력과 pair_key가 같은 문자열을 쓴다)

경로의 번호 표시를 공백으로 잇는다. 소수점 번호(1.1.7)는 그 자체가 번호다. `□`는 원문에 번호가 없어 문서 안 순서로 붙인다.

| 세트 | 원문 구조 | clause_no 예 | 조항 수 |
|---|---|---|---|
| S24 HWP | □ 덩어리마다 1.부터 다시 → 가. → ① / (1) | `□2 3. 아.` | 88 |
| S25 HWP | 제N장 → 1.1 → 1.1.7 → 1) → ① (3장은 3.2 → 1. → 1) → (1) → ①) | `1.1.7 2)`, `3.2 3. 8)` | 315 |
| S26 PDF | 1~47쪽 공통시방서(□, 첨부N, 서식N), 48~57쪽 제N장 → 1. → 1) → (1) → ① | `제2장 3. 8)` | 301 |

- 목차("목차" 줄부터 첫 항목이 본문에 다시 나오기 전까지)와 첫 조항 앞(표지)은 뺀다
- 번호가 이어지지 않는 줄(+1·+2도 1도 아님)은 끊긴 문장으로 보고 본문에 붙인다. 소수점 번호는 뒤에 한글 제목이 오고 장 번호와 첫 자리가 같을 때만
- 원문 특성 메모 2건 (S25): `2.3.7 10)` 원문이 8) 다음 10) (번호 건너뜀), `3.2 3.` 원문 "3 냉매 배관" (마침표 없음)
- S26 글자층 없는 쪽: 23~47 (25쪽). V4 후보로 기록만 한다 (정답셋 메모의 22~47과 1쪽 차이: 22쪽은 '첨부5 그라운드 룰' 제목 글자가 있음)

## 결정 (2026-11-25 김선진)
